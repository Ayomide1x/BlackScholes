# Black–Scholes option pricer

An interactive option pricer: Black–Scholes, plus a binomial tree for American options, Monte Carlo simulation (including Asian options), Heston's stochastic volatility, Merton's jump-diffusion, and Black-76 for options on futures.

https://blackscholes.ayomideo.dev

## What it does

- Prices a call and a put from spot, strike, time to maturity, volatility and the risk-free rate, plus each model's own inputs. For Black–Scholes the formula is shown with your numbers substituted in; the binomial and Merton models show how far their price is from Black–Scholes.
- Shows all five Greeks (delta, gamma, vega, theta, rho) for both options, in trader units: vega and rho per percentage point, theta per day.
- Draws call and put heatmaps across a range of spot prices and volatilities. The range follows your inputs, or you can set it yourself.
- Plots option value today against payoff at expiry across spot prices.
- For Monte Carlo, shows each price with a 95% confidence interval and a chart of the estimate settling as paths are added.
- For Heston and Merton, draws the implied-volatility smile: the Black–Scholes volatility each strike's price implies, for three maturities.

Everything recalculates in the browser as you type or drag, so there is no server round trip. The slower models (binomial, Monte Carlo and Heston) run in a Web Worker so the page stays responsive: the heatmap fills in row by row, and changing an input cancels the work in progress.

## Layout

- `web/`: the app (React, TypeScript and Vite). Each pricing model is a file in `web/src/models/` implementing the `Model` interface in `types.ts`. The tests check every model against Python reference values generated by the scripts in `web/scripts/`.
- `api/`: Heston calibration to the market. Once a weekday a job fetches an SPX option chain and Treasury yields, cleans the quotes (forward from put-call parity, out-of-the-money options only, a strike band that widens with maturity), fits Heston's five parameters by least squares, and stores the fit, the raw snapshot and the run's outcome in SQLite. A small FastAPI app serves the results under `/api`. The Python Heston pricer is tested against the same reference values as the frontend's.
- `Dockerfile`, `api/Dockerfile`, `docker-compose.yml` and `deploy/`: the production containers and the shared Caddy site block. See [DEPLOY.md](DEPLOY.md).
